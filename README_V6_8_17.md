# Nicole Puzzle Coach V6.8.17 – Median-normalized Form & Readiness

Form and WM-Readiness are now difficulty-neutral.

For each 500-piece puzzle:
- only Nicole's latest Solo attempt is used
- that time is compared with the official MSP Solo median for the same puzzle
- one puzzle = one current sample
- hard puzzles no longer reduce Form/Readiness merely because their raw times
  are longer

Form:
- average % above/below MSP median across the latest comparable puzzles
- positive = faster than median
- negative = slower than median

Consistency:
- variation of median-relative performance, not raw times

WM-Readiness weighting:
- 45% median-relative performance
- 25% normalized consistency
- 15% median hit rate
- 10% recency
- 5% comparable sample volume
- modest current training-load penalty

No own puzzle-time prediction is introduced.
No database migration.
