# Nicole Puzzle Coach V6.8.19

- WM-Readiness no longer includes training load.
- Improvement can only add bonus points; it cannot reduce readiness.
- Median hit logic exposes exact hit count and miss count.
- Readiness proof shows the exact last comparable 500-piece puzzles:
  latest Solo time, official MSP median, hit/miss, and percentage difference.
- This makes it possible to verify immediately whether the last 10 are being selected and compared correctly.
