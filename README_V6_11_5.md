# V6.11.5 – MSP Tournament Diagnostics

Adds a read-only tournament diagnostic path.

Checks:
1. Authentication token
2. MSP profile call
3. Official confirmed-competitions helper
4. Raw upcoming competitions endpoint
5. Participation detection for likely relevant championships
6. Confirmed competitions stored in the last successful snapshot

UI:
- More -> MSP Turnier-Diagnose
- One button renders each step with OK/error/count/timing.

No coach/readiness/training formulas are changed.
No tournament data is manually invented.
